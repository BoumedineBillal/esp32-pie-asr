esp32-pie-asr

Live English speech recognition on the ESP32-P4: the board's microphone in, the words on its screen as you speak, with no cloud; and six demos driven by spoken orders. Install it from this page in a few minutes.

What this page does

It writes the program (the firmware) into the board's flash memory, from your browser. The browser talks to the board over a USB cable; the flashing tool runs inside this page. Nothing is installed on your computer: no drivers, no ESP-IDF, no Python. The firmware file comes from this site; GitHub builds it from the public source code for each release.

It does not put the model on the microSD card. The browser cannot reach the board's card, and the model (26.65 MB) is too big for the board's flash. You copy it to the card yourself with your computer (step 1); at each start the board reads it from the card into its memory.

What you need

  • Espressif's ESP32-P4X-Function-EV-Board (ESP32-P4 chip revision v3) with its screen. Older ESP32-P4 boards (chip revision v1) cannot run it; the installer refuses them.
  • A microSD card formatted FAT32: a card of 32 GB or less usually is. Larger cards come as exFAT, which the board cannot read.
  • A USB-C cable that carries data (some cables only charge).
  • Chrome or Edge on a computer (Windows, macOS or Linux). Firefox, Safari and phones cannot flash boards.

Install

  1. Put the model on the microSD card.

    Download it, then copy kroko-en-q24-v1.bin to the top folder of the card (not inside a folder). Put the card in the board's microSD slot.

    Download the model (26.65 MB)
  2. Connect the board.

    Plug the cable into the board's USB Serial/JTAG port (a USB-C port; not the USB 2.0 High-Speed one) and into this computer.

  3. Install the firmware.

    Click Install and choose the board in the list (it is named USB JTAG/serial debug unit). Accept to erase the board. It takes about a minute; the board then restarts on its own.

    This browser cannot flash boards: open this page in Chrome or Edge on a computer. Flashing needs this page over HTTPS.
  4. Use it.

    The board reads the model from the card (about 3 seconds), then shows its home page. Choose Live transcription, press Start microphone and speak English; the words appear a moment after you say them. Voice control has the six demos: open one, press Start mic and say an order.

If something goes wrong

The list of ports is empty
The cable is in the other USB port of the board, or it only charges: use the USB Serial/JTAG port, or another cable.
The installer cannot connect to the board
Put the board in download mode: hold its BOOT button, press and release RESET, release BOOT. Then click Install again.
The installer says the board is not supported
It is not an ESP32-P4 of chip revision v3 (an ESP32-P4X).
The screen says the microSD card cannot be read
The card is missing or not FAT32. Format it as FAT32 (a card of 32 GB or less), copy the model again, restart the board.
The screen says there is no model, or that it is damaged
Copy kroko-en-q24-v1.bin again to the card's top folder, then restart the board.
